title: "Redirect Chain"

```
GET /v1/tools/http/redirects
```

Walk a URL redirect chain hop by hop with status codes and timings. Public — **no authentication required**.

Returns the standard [report envelope](/docs/tools). Tool id: `redirect_chain`.

## Query parameters

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| `url` | string | yes | URL to trace. A bare hostname is treated as `https://` |

## Request

```bash
curl "https://api.example.com/v1/tools/http/redirects?url=https://example.com"
```

## What it checks

- Disables automatic redirect following and walks each hop manually, capped at 10.
- Records status, destination, scheme and timing per hop.
- Detects loops and flags plain HTTP appearing after the first hop as a downgrade.
- Reports the final destination status, so a redirect ending in a 404 is caught.

## Findings

| Finding id | Status | Meaning |
| --- | --- | --- |
| `no_redirects` / `chain_length` | pass/warn/fail | Chain length; one hop passes, four or more fails. |
| `loop` | fail | The chain cycles. |
| `too_many` | fail | Still redirecting after 10 hops. |
| `https_upgrade` | pass | HTTP entry point redirects straight to HTTPS. |
| `http_downgrade` | fail | The chain drops back to plain HTTP mid-way. |
| `no_https` | fail | The site never redirects to HTTPS. |
| `temporary_redirect` | warn | A 302 or 307 used for what may be a permanent move. |
| `final_client_error` / `final_server_error` | fail | The destination returns 4xx or 5xx. |

## Response `200`

The `raw` object for this tool:

```json
{
  "start": "http://example.com",
  "final_url": "https://example.com/",
  "final_status": 200,
  "hops": [
    {
      "position": 1,
      "url": "http://example.com",
      "status": 301,
      "status_text": "Moved Permanently",
      "location": "https://example.com/",
      "scheme": "http",
      "latency_ms": 42
    }
  ],
  "total_ms": 170,
  "truncated": false,
  "plain_http_in_chain": true
}
```

## Errors

| Code | HTTP | When |
| --- | --- | --- |
| `BAD_REQUEST` | 400 | `url` is missing, or not a usable URL |
| `FORBIDDEN` | 403 | The target resolves to a private or internal address |
| `RATE_LIMITED` | 429 | More than 60 requests in a minute from one IP |
| `INTERNAL_SERVER_ERROR` | 500 | The check failed unexpectedly |
